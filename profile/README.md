## BWMeter Highlights

- **Traffic Graph:** BWMeter traffic graph shows speed on the computer or small network link you are measuring.
- **Filter Rule:** BWMeter filter rule separates traffic by a host, a port, or another condition you define for your own link.
- **Speed Cap:** BWMeter speed cap limits how fast a filtered flow may go, so one backup does not take a study hour.
- **Host Usage:** BWMeter host usage shows which machine on your home or office LAN is using the link.
- **Weekly Chart:** BWMeter weekly chart rolls the days into one week so a pattern is easier to see than a single spike.

## What Is BWMeter

BWMeter is a bandwidth helper that both measures and, when you ask, slows a flow on a link you control. BWMeter traffic graph is the live view. BWMeter filter rule decides which part of that traffic you are looking at. A family network, a student apartment, or a very small office can see local use without a larger monitoring suite.

BWMeter host usage names the computer on that LAN. BWMeter speed cap is optional: use it when a backup or a large study download should leave room for a call or a class. BWMeter weekly chart shows whether the cap and the busy hours repeat. These controls apply to your own link, not to traffic on networks you do not operate.

Look first. Read BWMeter traffic graph, BWMeter filter rule, and BWMeter host usage before you set BWMeter speed cap. After a few days, BWMeter weekly chart tells you whether the limit was aimed at the right hour. A calm setup is one cap, one or two filters, and a chart you can explain.

## Starting with BWMeter

Prerequisites: A compatible computer on a link you control, and permission to run BWMeter.

1. **Prepare:** Watch a normal hour before you change any speed.
2. **Open The Graph:** Read BWMeter traffic graph during that hour.
3. **Name A Flow:** Add one BWMeter filter rule for a backup or another flow you recognize.
4. **See The Computer:** Check BWMeter host usage so you know which machine it is.
5. **Cap Gently:** Set a modest BWMeter speed cap only if that flow crowds study or work.
6. **Wait A Week:** Read BWMeter weekly chart before you add a second cap.
